# Backend endpoint gaps

A running list of endpoints the frontend needs that don't exist yet, and existing ones that need rework. This is the source for the tracking sheet. Status is **Not fixed** until the backend confirms a fix.

Last updated: 2026-10-27

## Since the last update (2026-10-26)

- **Fixed:** R4. `DecisionDto` no longer has `decision`; the frontend has stopped sending it.
- **New and now used (2026-10-27):** `begin-devwork-review` and `review-devwork-&give-conclusion`. M11 is fixed.
- **Fixed (2026-10-27):** R10. Ticket, task and history responses and statuses are now documented.
- **New (2026-10-27):** R23, `reject-ticket` no longer takes a reason. R24, response shape problems for tickets and tasks.
- **Changed (2026-10-27):** `create-parent-ticket` now requires `documentProductId`. The PM picks one of the initiative's approved documents on the ticket form, and the frontend sends it.
- **New (2026-10-27):** R22, `configure-workflow` returns a generic error.
- **New gap (2026-10-27):** M22, full names on user lists.
- **Partly fixed (2026-10-27):** R7. The Product Manager can now read `get_all_users`. The Lead Engineer and the other non-admin roles still can't.
- **Partly fixed:** R2. Documents now return `commentReview`, which the PM sees as the reason a document was returned. Still missing: who returned it, when, and `submittedAt`.
- **Renamed:** `preview-pdf` is now `preview-generated-pdf`. The frontend uses the new name. See R6.
- **New endpoints now used by the frontend:**
  - document approval workflow: `configure-workflow`, `submit-workflow`, `my-pending-workflow`, `sign-and-approve`, `reject-approval`;
  - the three workflow PDFs;
  - every ticket and developer-task endpoint.
- **New, not used yet:** Departments (`/api/departments/...`). No frontend screen needs them so far.
- **Simulated on the frontend until the backend adds them:**
  - M8–M10 and M12 (ticket and task lists, ticket completion);
  - M13–M15 (reading workflows and sign-off history);
  - M19 (AI).

  Each screen shows a yellow notice where data is simulated.

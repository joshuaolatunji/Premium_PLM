A running list of endpoints the frontend needs that don't exist yet, and existing ones that need rework. This is the source for the tracking sheet. Status is **Not fixed** until the backend confirms a fix.

Last updated: 2026-11-09

## Backend priority (memos)

Memos stay a preview, with no real users, until every P1 item is fixed.

- **P1, release blockers:**
  - M33 and M26: access control. Any user can read any memo, and every memo is sent to everyone.
  - (M39 is now P2: document `my-assigned-memo` in Swagger, and reviewer names.)
  - M35: the author starts signing (to retest).
- **P2:**
  - M36: signing history in the register.
- **P3:**
  - M28: `update-memo` blanks fields it isn't sent.
  - M29: response and Swagger fixes.
